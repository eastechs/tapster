# Textend 0.3.1

- Follow a first-launch setup guide that explains Accessibility permission, opens System Settings, and detects when access is ready. You can set up expansion later from Settings → Permissions.
- Import and export backups from Settings → Backups, including when the Dock icon is hidden.
- Choose Restart Now or Not Now after changing Dock visibility. Textend checks for unsaved edits before restarting.
- Use a more compact Quick Access panel, with less empty space and insertion guidance beside the action buttons.

If you use iCloud sync, update Textend on every Mac before using app-specific collections. Older versions cannot enforce app restrictions or display Compositions.
