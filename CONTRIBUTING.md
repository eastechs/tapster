# Contributions

Textend is open source, but external code contributions are currently closed.
Pull requests are disabled. Please do not submit patches through issues or email.

Bug reports and feature requests are welcome through
[GitHub Issues](https://github.com/eastechs/tapster/issues). Include your Textend
version, macOS version, steps to reproduce, and expected behavior. Remove private
snippet content and clipboard data before sharing screenshots or diagnostics.

You can build, modify, and redistribute the code under the [MIT license](LICENSE).
Use your own name and icon for a distributed fork; see [TRADEMARK.md](TRADEMARK.md).
The [README](README.md) describes the build prerequisites and tests.

Report security problems privately to <security@eastechs.com> instead of opening
a public issue.
