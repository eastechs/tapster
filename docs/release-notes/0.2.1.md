# Textend 0.2.1

- Sort snippets alphabetically or by creation date, with newest first. Textend remembers your choice.
- Preview snippets with an empty sample clipboard by default.
- Use copied file paths in Clipboard placeholders, including images copied from CleanShot when a file reference is available. Image-only clipboard contents without a file reference are not converted into files.
- Keep Textend in true menu-bar-only mode when the Dock icon is disabled. This takes effect after restarting and avoids changing Dock mode when windows close.
- Match the running Dock icon to your selected theme color. Finder and Spotlight retain the installed blue icon.
- Improve the sort control's alignment in the snippet-list header.

Textend's source code is now available under the MIT license. Bug reports and feature requests are welcome; external code contributions are currently closed.
