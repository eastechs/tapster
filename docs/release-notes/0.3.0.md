# Textend 0.3.0

- Open Quick Access with Shift-Command-Space to find and insert saved snippets and Compositions. Change the shortcut in Settings.
- Limit collections to selected apps and reuse keywords across different app collections.
- Build Compositions from existing snippets and literal text, with configurable spacing and cursor placement.
- Browse Compositions in their own sidebar section. Favorites includes both snippets and Compositions.
- Start editing the name immediately when creating a new item, with larger clickable areas for library controls.
- Preserve keyword matching when correcting typos with Backspace.
- Prevent macOS from inserting a period when an expansion contains consecutive spaces.

If you use iCloud sync, update Textend on every Mac before using app-specific collections. Older versions cannot enforce app restrictions or display Compositions.
